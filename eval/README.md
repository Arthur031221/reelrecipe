# Recipe extraction evaluation

`demo/sample.mp4` is a synthetic smoke test. It is not a recipe accuracy benchmark.

The next evaluation should use ten public-domain or Creative Commons cooking videos. Record the source URL, license, creator, and download date for each clip. Do not commit large video files. Write a reference list of ingredients and steps from the full video before running the extractor. Count an ingredient as recalled when the exported recipe names the same food, independent of quantity spelling. Report recall as matched reference ingredients divided by all reference ingredients, both per video and pooled. Review hallucinated ingredients separately. Record the model versions, frame count, hardware, date, and exact commands.

Do not publish an accuracy number until the sources and reference annotations are available for review.
