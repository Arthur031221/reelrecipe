# Contributing

Open an issue with a short example before making a large change. Keep videos and model files out of Git. Small public or synthetic fixtures are welcome when their source and license are clear.

Run `uv sync --group dev --locked`, `uv run ruff check .`, and `uv run pytest -q` before opening a pull request. Include the input type, expected recipe fields, and actual output for extractor bugs. Remove personal data from transcripts and recipe files.
